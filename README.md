# Cartografia Estelar
Mapa estelar 3D interativo (79 corpos, 15 sistemas, 6 galáxias) — HTML único + Three.js, sem build.

**Rodar:** abra `index.html` no navegador (a pasta `audio/` precisa estar junto para a trilha; sem ela, toca a música generativa).
**Publicar:** suba a pasta inteira no GitHub Pages ou qualquer estático.
**Continuar com IA:** abra a pasta no VS Code com Claude Code — o `CLAUDE.md` carrega todo o contexto do projeto.
