    MANUAL DO NAVEGADOR

    Toque em um corpo para catalogar. Toque de novo (ou use o botão ▶ do card) para entrar.

    Arraste para girar · scroll para aproximar · pinça para aproximar. Os botões + / − também ajustam o zoom.

    Afaste o zoom até o limite para subir de escala: Corpo → Sistema → Galáxia → Universo. Ele trava no limite: afaste de novo para subir. A trilha no topo também navega.

    Botões ‹ › saltam entre planetas ou luas vizinhas, assim como as setas do teclado.

    ⚖ Comparar: toque no botão do card, abra outro corpo e toque de novo: análise lado a lado em escala real.

    ◈ Registro de bordo: a lista completa do catálogo, com o que você já visitou, sua patente, busca e filtros por habitáveis, planetas, luas, estrelas e regiões.

    ◉ Modo foto: esconde o painel inteiro para uma captura limpa. Um toque longo na tela faz o mesmo (ou a tecla P).

    ▶ Modo tour: dentro do registro de bordo (ou pela tecla T), o mapa se guia sozinho por uma rota comentada. Toque na cena a qualquer momento para assumir o controle.

    Compartilhe: o endereço da página acompanha o objeto (ex.: #corpo=europa), copie o link e envie.

    ESC volta um nível · / busca · M registro · T tour · P foto · ? este manual

    Dados: NASA/ESA/IAU, valores aproximados. Linhas em âmbar são referências de ficção.
